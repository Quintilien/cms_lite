# config/ — configuration: never inside the web root

`config.ini` (created from `config.ini.example`) names the site's database.
This folder stays **next to** the served folder, never inside it.
Plain text, UTF-8 without BOM.

**FR —** `config.ini` (à créer depuis `config.ini.example`) désigne la base du site. Ce dossier reste **à côté** du dossier servi, jamais dedans. Texte brut, UTF-8 sans BOM.
