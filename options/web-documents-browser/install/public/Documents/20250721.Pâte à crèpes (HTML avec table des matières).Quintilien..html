Pâte à crèpes

Ingrédients

  • Farine : 250 g
  • Oeufs : 4
  • Lait : ½ litre
  • Sel : 1 pincée
  • Sucre : 2 cuillère à soupe
  • Beurre fondu : 50 g

Préparation

  • mettre la farine dans un saladier
  • ajouter le sucre avec le sel et le sucre
  • faire un puits au milieu et y verser les œufs
  • mélanger doucement
  • quand le mélange devient épais, ajouter petit à petit le lait froid
  • une fois le lait mélangé, la pâte doit être assez fluide
  • au besoin, rajouter un peu de lait
  • ajouter ensuite le beurre fondu (refroidi)
  • mélanger

Cuisson

  • faites cuire les crêpes dans une poêle chaude (légèrement huilée si la poêle à crêpes n’est pas anti-adhésive)
  • verser une petite louche de pâte dans la poêle
  • effectuer un mouvement de rotation pour répartir la pâte sur toute la surface
  • poser sur le feu
  • quand le tour de la crêpe se colore en roux clair, la retourner
  • laisser cuire le deuxième côté pendant environ une minute
