##### Il est désormais indispensable que le format d'affichage s'adapte à l'écran utilisé : 

- ordinateur
- tablette
- smartphone
- en mode "portrait" 
- en mode "paysage"



 <--->

### Il faut donc dissocier 

- **le contenu** (le texte) 
- **l'habillage** (le style) 
- **le contenant** (word, pdf, etc), qui influence l'*affichage* et la *présentation*.

# Markdown répond à ces critères

- Un fichier Markdown est un *simple fichier texte* qui pourra toujours être lu par des applications basiques (Notepad sur PC, Textedit sur Mac et bien d'autres encore)
- L'information est indépendante d'un *format propriétaire* ou non (Microsoft Word, Adobe Pdf, etc)
- Il s'agit néanmoins d'un format reconnu par un grand nombre d'applications ou de sites (WordPress, GitHub, etc)
- **En enregistrant une information dans un fichier au format Markdown, on en garantit la perennité**.
- Markdown peut être associé à une "feuille de style" : on obtient alors des mises en page esthétiques, qui s'adaptent aussi bien au mode "paysage" sur une tablette  qu'au mode "portrait" sur un SmartPhone !

![](images/word_markdown/ecr300.png)

# Comment ça marche ?

- Le texte brut contient juste quelques "repères" (appelés *balises*) qui indiquent la "nature" du texte qui suit : titre, sous-titre, liste, etc 
- Petite particularité : les images sont enregistrées séparément du texte.   Le texte considère l'image comme un lien auquel il est fait référence.

Le Web regorge d'explications et de mode d'emploi généralement bien faits, notamment
